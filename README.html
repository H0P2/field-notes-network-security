  • 아래 기록 중 배포 전 상태는 당시 검사 시점의 기록입니다. 이미지·그라데이션 위 텍스트 대비는 아래 단색 대비 계산으로 인증되지 않았으므로 T01-C16 전체 통과를 주장하지 않습니다.

2026-10-04 배포 전 버전 점검

홈에 관심 분야, 본인이 요청한 행동 세 가지, AI가 수행한 결과 및 근거 링크를 요약했습니다. 이 문안은 사용자 대화와 보존된 보고서에 근거하며, 본인이 직접 코드를 작성하거나 ASA 실습을 마쳤다는 주장은 포함하지 않습니다. 최종 개인 판단과 공개 범위는 사용자 확인이 필요합니다.

스크롤 카메라에 시간 기반 보간을 추가하고 메뉴 전환을 0.65초로 조정했습니다. 로컬 두 기준 화면(1366×768, 1920×1080)의 소개·활동·근거 링크 및 가로 넘침 0px을 확인했습니다. 결과 이미지 6개의 Esc 닫기·초점 복귀, 근거 펼치기 클릭·Space·Enter, 움직임 줄이기를 확인했습니다.

실제 수정 전후: 스크롤 입력 즉시 반영 → 짧은 보간; 화면 진입 시 h1 접근 불가 → h1 유지; 하단 구분점 대비 2.97:1 → 9.12:1; 옛 확인 위치 → DASHBOARD 목록으로 정정.

단색 배경 텍스트 185개는 대비 기준 통과이며, 이미지·그라데이션 위 39개는 이 계산으로 인증하지 않았습니다. 현재는 로컬 미리보기로, 공개 URL·시크릿 창 접근·Git 이력·최종 공개 범위와 본인 판단은 완료 전입니다. 아래 2026-10-02 기록은 이전 버전의 검사입니다.

최신 변경: 노트북 진입 장면을 추가했습니다. laptop-scene.css와 entrance.js가 장면을 제어합니다. 이전 세 자세 캐릭터 안내는 이 장면으로 대체되었습니다.

최신 변경: 캐릭터·UI 개편. 관절 SVG 안내자를 고해상도 캐릭터 세 자세로 교체하고 첫 화면과 상세 페이지를 다시 정리했습니다.

2026-10-02 개편한 개인 소개 사이트입니다. 실제 자료를 다룬 프로젝트 5개, 작업 기준, 공개 범위와 근거를 보여줍니다. ASA 장비 실습은 보류 상태이며 성과로 집계하지 않습니다. 구현·분석은 AI가 수행했고, 사용자에게 확인되지 않은 개인 이력은 만들지 않았습니다.

로컬 실행

Python 3.10 이상에서 이 폴더를 기준으로 실행합니다.

python build_evidence_pages.py
python -m http.server 8765 --bind 127.0.0.1

브라우저에서 http://127.0.0.1:8765/를 엽니다. 로컬 미리보기이며 제출용 공개 URL은 아닙니다. 보고서나 코드를 바꾸면 HTML 생성 명령을 다시 실행합니다.

디자인과 동작

참고 이미지의 청록색 서버실 조명, 천장 배선, 여러 모니터가 있는 작업 공간을 CSS 3D 평면과 SVG로 구성했습니다. 연구실은 공간 연출이며 실시간 관제 화면이 아닙니다. 모니터의 수치는 검토된 오프라인 보고서에서 가져왔습니다.

스크롤하면 연구실 시점의 각도와 깊이가 바뀝니다. 상단의 움직임 줄이기 버튼, 운영체제의 prefers-reduced-motion, 모바일 고정 장면을 지원합니다. 스크롤 이벤트가 있을 때만 화면을 갱신하며 외부 3D 라이브러리나 CDN은 사용하지 않습니다.

결과 이미지 6개는 페이지 안에서 확대됩니다. Esc, 닫기 버튼, 배경 클릭으로 닫으며 원래 링크로 초점이 복귀합니다. JavaScript가 없으면 원본 이미지 링크와 근거 링크를 그대로 사용할 수 있습니다.

프로젝트 재검토

재검토 결과에는 실제 입력 재실행, AuthSentry·PublishGate의 입력 검증 결함 수정 전후, 한계를 기록했습니다. SampleScope는 보관된 CTU-13 세 구간 총 46,023행을 비교합니다. 시작 구간의 비 IP 주소 1행은 FlowLens 분석 범위에서 제외됩니다.

이번 브라우저 점검

  • 1366×768, 1920×1080의 첫 화면에 소개·활동·근거 링크와 결과 요약을 확인했습니다. 두 화면과 모바일 390px에서 문서 가로 넘침은 0px입니다.
  • 스크롤 전후 3D 각도와 깊이 값의 변화, 이미지 6개 로드·확대·Esc 닫기·초점 복귀를 확인했습니다.
  • 이미지 링크 Enter 열기, 닫기 버튼 Space, 움직임 버튼 Space·Enter 전환을 확인했습니다.
  • 이 점검에서 홈페이지 콘솔 오류는 0건입니다. 외부 원본 사이트의 현재 무로그인 접근 여부와 최종 공개 배포는 아직 확인하지 않았습니다.

이번 화면 작업 중 수정한 실제 문제

  1. 3D 천장과 배선이 장면 밖으로 넘어와 소개 문구에 겹쳤습니다. 장면 영역을 자르고 불필요하게 가리는 천장 평면을 제거했습니다.
  2. 화면 크기별 배율이 위치 변환과 결합되어 모니터 일부가 잘렸습니다. 배율을 중앙 정렬 뒤에 적용하도록 변환 순서를 고쳤습니다.
  3. SampleScope를 추가한 뒤 SecretFence 카드와 PNG에 이전 파일 수가 남았습니다. 현재 패키지에서 다시 스캔하고 같은 검사 결과로 문구·PNG·보고서를 갱신했습니다.

이전 버전에서는 Markdown/Python 원문 링크의 브라우저 차단, HTML 제목 중복, 파비콘 404를 수정했습니다. 보고서와 코드는 HTML 읽기 화면으로 연결합니다.

공개 범위와 검사 제한

공개 후보: 사용자가 선택한 작업 기준, 집계값·표본 한계, 코드와 보고서. 제외: 실명·사진·연락처, 기관·정확한 위치, 원시 식별자와 비밀값. 원본 표본은 배포 폴더 밖에 있습니다.

최신 SecretFence 검사는 지정된 텍스트 패턴과 제외 범위를 표시합니다. PNG는 바이너리라 텍스트 검사에서 제외되며, 현재 폴더는 Git 저장소가 아니므로 Git 이력은 미검사입니다. 공개 저장소를 만들면 그 최종 이력도 별도로 확인해야 합니다.

공개 결과 주소와 공개 소스 저장소 주소는 아직 없습니다. 최종 공개 범위·소개 문안과 공개 위치를 확정한 뒤 배포합니다.

짧은 확인법

위치: DASHBOARD 페이지의 프로젝트 목록으로 갑니다.

행동: 결과 이미지 클릭 → Esc → 같은 링크에서 Enter를 누릅니다.

통과: 확대창이 닫히며 링크로 초점이 돌아오고 Enter로 다시 열립니다.

실패: 이미지 파일로 페이지가 이동하거나, Esc로 닫히지 않거나, 초점이 사라집니다.
