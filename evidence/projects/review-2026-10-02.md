# 프로젝트 재검토 — 2026-10-02

## 실제 입력 재실행

FlowLens와 AuthSentry를 보관된 실제 원본 표본으로 다시 실행했습니다. 두 Markdown 보고서의 재생성 내용이 기존 보고서와 완전히 일치하며 입력 SHA-256도 일치합니다. 원격 자료를 새로 다운로드한 검사는 아닙니다.

| 프로젝트 | 실제 재실행 결과 | 범위 |
| --- | --- | --- |
| FlowLens | 15,313 흐름 · 제외 0행 · 기존 보고서와 일치 | 선택한 중간 약 2 MiB 구간 |
| AuthSentry | 58,334 세션 · 제외 0행 · 기존 보고서와 일치 | 압축 prefix의 완전한 JSONL 행 |
| PublishGate | 원본 manifest 보고서 2개 통과 | 원본 재계산이 아닌 패키지 검사 |
| SecretFence | 최신 사이트 검사 기록 참조 | 패턴 기반 텍스트 검사, Git 이력 별도 |

## 재현한 결함과 수정

| 위치 | 수정 전 실제 관찰 | 수정 후 실제 관찰 |
| --- | --- | --- |
| AuthSentry parse_count | 경계값 1.5가 1로 잘려 수락됨 | ValueError로 거부. 정상 정수와 정수 문자열은 수락 |
| AuthSentry parse_count | 무한대 경계값이 처리되지 않는 OverflowError 발생 | ValueError로 정리되어 레코드 검증에서 제외 가능 |
| PublishGate | 실제 manifest 사본에서 기록 수만 15,314로 바꿔도 통과 | 보고서 15,313과 불일치로 거부. 원본 manifest는 통과 |

위 경계값과 변형 manifest는 검증 로직을 검사하기 위한 통제 입력입니다. 관측 데이터나 새로운 실험 성과 수치로 사용하지 않았습니다. 실제 데이터 결과는 수정 전후 동일합니다.

## 추가 실험에서 발견한 범위 차이

SampleScope는 CTU-13 시작·중간·끝 3개 원본 구간의 해시를 확인하고 총 46,023행을 집계했습니다. 시작 구간의 IPX/SPX 1행은 IPv4/IPv6 주소 형식이 아니어서 FlowLens에서 제외됩니다. 원본 CSV 15,279행과 FlowLens 분석 15,278행을 명시적으로 구분했습니다. 이는 지원 범위 차이이며 억지로 IP 흐름으로 변환하지 않았습니다.
